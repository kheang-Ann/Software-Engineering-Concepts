# Lab7 Concurrency Tasks

This repository contains solutions for four concurrency problems.

## Prerequisites

- Java Development Kit (JDK) installed.

## Execution Instructions

To run any of the tasks, navigate to the appropriate subdirectory, compile the Java source files, and then run the main class.

### Task 1: Bank Account

1.  Navigate to the `Task1` directory:
    ```sh
    cd Task1
    ```
2.  Compile the Java files:
    ```sh
    javac *.java
    ```
3.  Run the demo:
    ```sh
    java BankDemo
    ```

### Task 2: Producer-Consumer

1.  Navigate to the `Task2` directory:
